# Diagrama Sistema Biblioteca
Un diagrama de clases UML es el plano visual y estructural que define de forma clara las clases, atributos, métodos, multiplicidades y tipos de relaciones de un sistema , actuando como el puente directo entre la abstracción conceptual y la implementación física en la programación orientada a objetos.

# S35 EA1 Diagrama de clases Biblioteca
Repositorio para la evidencia del diagrama de clases UML de un sistema de gestión de biblioteca, correspondiente a la asignatura de Programación Orientada a Objetos.El modelo estructural implementa buenas prácticas de diseño, encapsulamiento de datos y el principio de Responsabilidad Única (SRP), estableciendo relaciones lógicas de composición, agregación y asociación.
