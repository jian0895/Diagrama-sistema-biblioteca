# S35 EA2: Implementación de Diagrama de Clases - Sistema de Biblioteca

Repositorio para la evidencia de la implementación en Java de un sistema de gestión de biblioteca, correspondiente a la asignatura de **Programación II: Orientada a Objetos Avanzada**.

El proyecto consiste en llevar a código el diagrama de clases realizado anteriormente, creando las diferentes clases del sistema y sus relaciones. Se trabajaron conceptos de programación orientada a objetos como clases, atributos, métodos, herencia, encapsulamiento y polimorfismo.

## Clases del sistema

El sistema está compuesto por las siguientes clases:

- **Usuario:** Contiene la información de los usuarios de la biblioteca.
- **UsuarioConPrestamos:** Permite manejar los préstamos asociados a un usuario.
- **Bibliotecario:** Representa al personal encargado de la biblioteca.
- **Direccion:** Contiene la información de dirección de los usuarios.
- **Autor:** Contiene la información relacionada con los autores de los libros.
- **Libro:** Clase principal para representar los libros.
- **LibroDigital:** Representa los libros que se pueden consultar de forma digital.
- **LibroFisico:** Representa los libros disponibles en formato físico.
- **Prestamo:** Permite registrar los préstamos realizados entre los usuarios, bibliotecarios y libros.
